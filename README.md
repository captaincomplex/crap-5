# Crap-5

An interactive, unofficial flight-computer simulator. Open `index.html` in a browser, or use the GitHub Pages site.

## Controls

- Click the wind window to pencil a cross.
- Drag inside the wind window to move the speed grid.
- Drag the compass ring to rotate the disc.
- Use the named tool buttons to lock an action; Undo cross removes the last mark.
- Turn over for the circular slide rule, cursor and air-data settings.

Includes L/H wind grids, runway components, magnification and precision inputs.

## Status

This is an incomplete simulation, not an exact CRP-5 replica. Printed air-data windows, temperature-rise scales, full conversion datums and slide-edge rulers are not reproduced. Air-data calculations use separate inputs. For practice only; not for operational flight planning.

Reference: [Pooleys CRP-5 manual](https://www.pooleys.com/media/7870/crp-5-booklet-2017.pdf). This project is not affiliated with Pooleys.
